# wurtzite
Python package with software for crystallography. 

The package contains functions for:
- crystal structure definition and generation,
- crystal visualization,
- simulation of the crystal defect (dislocations),
- and many more...

## Installation


1. Clone this repository (branch article2026): `git clone -b article2026 https://github.com/pjarosik/wurtzite.git`
2. Create virtual environment in the current directory (e.g., you can `cd` to the wurtzite): `python -m venv venv`.
3. Activate virtual environment: `source ${venv_root}/venv/bin/activate`, where `{venv_root}` is the location where the venv has been created.
3. Install wurtzite package with the following command: `pip install -e /path/to/the/wurtzite/`.
